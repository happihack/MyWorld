# WORLD IN A BOX

## Milestone-Based Development Roadmap

### Godot 4.7.2 — Android First

Use this milestone roadmap to turn the full World in a Box specification into a sequence of small, testable, playable development stages.

## MOST IMPORTANT DEVELOPMENT RULE

**Do not attempt to build the complete game at once.**

The game has enormous potential, but its core risk is not the number of features.

The core risk is:

> **Does interacting with the tiny world actually feel magical?**

Therefore, prioritize the **toy → living world → simulation → civilization → history → mystery** progression.

Every milestone must produce a working build.

Every milestone must be:

1. Buildable.
2. Runnable.
3. Testable.
4. Debuggable.
5. Save-safe where applicable.
6. Performance-measurable.
7. Playable on Android once mobile functionality begins.

Do not add the next milestone simply because the code technically works.

First make the current milestone **feel good**.
